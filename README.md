# WEB-MAJO-MATEO

Web estática hecha para Maria Jose Pinto Palma y Mateo.

## Incluye

- Galería de fotos con carga desde el navegador
- Notas o recuerdos guardados localmente
- Calendario simple de citas
- Recomendaciones de panoramas
- Estética romántica, tierna e interactiva

## Uso

Abre `index.html` en el navegador.

## Nota

Las fotos, notas y citas se guardan en `localStorage`, así que quedan asociadas al navegador y dispositivo donde uses la página.
