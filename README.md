# WEB-MAJO-MATEO

Web estática hecha para Maria Jose Pinto Palma y Mateo.

## Incluye

- Inicio separado con mensaje principal personalizado
- Galería de fotos con carga desde el navegador
- Página de recuerdos y calendario de citas
- Página de planes con ideas predefinidas
- Creación de planes personalizados guardados localmente
- Diseño en blanco, rojo y celeste

## Estructura

- `index.html`: inicio
- `galeria.html`: fotos
- `recuerdos.html`: notas y citas
- `planes.html`: ideas y planes propios

## Nota

Las fotos, notas, citas y planes personalizados se guardan en `localStorage`, así que quedan asociados al navegador y dispositivo donde uses la página.
